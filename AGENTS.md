# AGENTS

## Regra obrigatória de versionamento

Toda alteração deve ser commitada e pushada.

- Após qualquer criação, edição ou remoção de arquivos, execute: `git add -A`, `git commit` com mensagem clara e `git push`.
- Nunca deixe alterações apenas locais ou sem push para o GitHub.
- Se o push falhar, corrija e tente novamente até confirmar que está no remoto.
